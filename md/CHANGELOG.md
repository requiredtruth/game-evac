# Changelog

## 0.3.0 — Evacuation Protocol

- Rebuilt deployment, objective, radar, contextual controls, vitals, squad and debrief screens for desktop and mobile.
- Added real shadow maps, tone mapping, procedural sky/clouds, warmer lighting and fine surface variation.
- Reworked character silhouettes, articulated limbs, hazmat equipment, wheels/hubs, headlights/glazing, architecture, foliage and the forward base.
- Added civilian vehicle transport with shared seat limits and LZ unloading.
- Added bounded A* obstacle routing, spatial collision indexing and intact-wall bullet occlusion.
- Added rifle magazines/reloading, stamina/sprinting, medic teammate treatment and engineer spare parts.
- Added hit/damage feedback, shared combat effects and synthesized ambient/combat/engine/footstep sound.
- Added JSON mission export/import, autosave, old-save migration, quality settings, mute and fullscreen.
- Split editable source from the generated standalone HTML and added reproducible-build verification.
- Expanded rule and browser coverage. Historical citywide accuracy and direct-co-op relay limits remain explicit.
